# VoteWise-JS 🗳️

A simple JavaScript project that checks whether a person is eligible to vote based on their age.

## 📌 Features

- Takes age as input
- Validates user eligibility
- Displays clear results
- Beginner-friendly JavaScript project

## 🚀 Technologies Used

- HTML
- CSS
- JavaScript

## 📖 How It Works

1. Enter your age.
2. Click the "Check Eligibility" button.
3. The application determines whether you are eligible to vote.
4. Results are displayed instantly.

## 🧠 Concepts Practiced

- Variables
- Data Types
- User Input
- Conditional Statements (`if-else`)
- DOM Manipulation

## 📂 Project Structure



## 🎯 Eligibility Rule

A person is eligible to vote if their age is **18 years or above**.

## 📸 Output Example

Input: 20

Output: You are eligible to vote ✅

Input: 16

Output: You are not eligible to vote ❌
